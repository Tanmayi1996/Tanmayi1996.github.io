# Documentation portfolio

This folder contains original documentation samples for the browser-based mini projects and developer tools in Tanmayi R S's portfolio.

The samples describe the implementation currently published on the portfolio site. The API examples use fictional services and data. They do not identify or document an employer's internal products.

## Editorial approach

These samples follow established technical-publication practices associated with MSTP and are informed by the public Microsoft Writing Style Guide. They use task-led headings, direct instructions, active voice, sentence-style capitalization, consistent terminology, and code formatting for literal values.

This is an independent portfolio adaptation. It is not an official Microsoft document or a reproduction of Microsoft's proprietary style manual. See [editorial notes](editorial-notes.md).

## Product and data notice

Atlas Workspace is a fictional product used to make examples consistent. The API hostnames, identifiers, endpoints, and payloads are illustrative. The browser mini tools run locally in the visitor's browser and do not connect to a production service.
