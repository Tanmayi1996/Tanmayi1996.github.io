Cross-tool checks

  • Open each tool from its project card and from the Mini projects section.
  • Switch tabs using pointer and keyboard input.
  • Check that selected tab and visible panel stay synchronized.
  • Check narrow and wide viewports.
  • Confirm text output remains selectable.
  • Confirm inputs are not sent to a server.
  • Check for browser console errors.

Accessibility checks

  • Navigate to each control with the keyboard.
  • Confirm that each input has a visible label.
  • Confirm that buttons have meaningful accessible names.
  • Confirm that the active tab exposes its selected state.
  • Confirm that status messages are announced by a live region.
  • Check focus visibility and text contrast in both themes.
  • Use a screen reader to verify heading and control order.

Release criteria

Publish a change when all applicable checks pass, the documentation matches the implementation, links work, and no sample credentials or personal information have been added.
