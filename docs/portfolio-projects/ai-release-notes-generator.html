AI Release Notes Generator

Run a deterministic Python command-line tool that turns structured product change records into grouped Markdown release notes.

Overview

The AI Release Notes Generator demonstrates a repeatable input model and consistent Markdown output. The current implementation is deterministic. It does not call an AI service or create product facts. A writer supplies the change records and reviews the result.

Run the generator

You need Python 3.10 or later. The project uses only the Python standard library.

  1. Clone the source repository.
  2. Open the ai-release-notes-generator directory.
  3. Run the following command:
python generate.py changes.json --output RELEASE_NOTES.md

Open RELEASE_NOTES.md and review the draft.

Prepare the input file

The input file is JSON. It contains product metadata and a changes array. Each change requires the following fields.

FieldTypeDescription
typestringChange category: feature, improvement, fix, security, or deprecated.
titlestringShort customer-facing change title.
descriptionstringDescription of what changed.

Optional fields include audience, which defaults to all, and area, which adds product-area metadata. The top-level product, version, and release_date fields identify the release.

Understand the output

The generator groups changes in a fixed order: new features, improvements, bug fixes, security, and deprecations. Empty categories are omitted. Each change becomes a bullet with its title, description, and optional audience and product-area metadata.

Validate the input

The generator stops with an error when changes is not an array, a required change field is empty, or the change type is not supported.

python -m unittest -v

Editorial review

The generated Markdown is a draft. Before publishing, confirm that each change is customer-visible, available in the stated release, and described with approved terminology. Add prerequisites or rollout details when they affect the reader.

Implementation limits

The tool does not read issue trackers, source-control commits, or product roadmaps. It does not summarize pull requests, infer customer impact, or validate release status. Its value in this sample is the structured input model and repeatable Markdown output.
