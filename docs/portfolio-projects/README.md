# Code-based portfolio projects

The portfolio includes three runnable projects in addition to the four browser-based mini tools. The source code is maintained in the [technical writing portfolio repository](https://github.com/Tanmayi1996/tanmayi-portfolio).

## Project summaries

| Project | Primary capability | Main artifacts |
|---|---|---|
| [AI Release Notes Generator](ai-release-notes-generator.md) | Converts structured change records into grouped Markdown release notes | Python CLI, JSON input, unit tests |
| [API Documentation Toolkit](api-documentation-toolkit.md) | Documents a fictional REST API using an OpenAPI contract and a reader-facing guide | OpenAPI 3.1 YAML, API guide, structural checker |
| [Documentation Quality Checker](documentation-quality-checker.md) | Checks Markdown for common mechanical issues | Python CLI, sample Markdown, unit tests |

## How these differ from the browser demos

The browser mini tools run in the portfolio page and are designed for quick interaction. The code-based projects have source files, command-line instructions, test cases, and project-level READMEs. The API contract uses fictional routes and a reserved example hostname.
