Project overview

These samples demonstrate documentation for small developer tools. Each guide describes what the current implementation does, how to run it, which inputs it accepts, and where its validation stops.

How these differ from the browser demos

The browser mini tools run in the portfolio page and are designed for quick interaction. The code-based projects have source files, command-line instructions, test cases, and project-level READMEs. The API contract uses fictional routes and a reserved example hostname.
